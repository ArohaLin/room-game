# 🔑 回家的鑰匙(Homecoming Key）

一款**溫馨家庭密室解謎**網頁小遊戲。放學的午後,小主角提早回到家,卻發現大家都不在……當一回小偵探,在一棟四層樓的家裡一層一層找出家人的祕密,最後迎來溫暖的團圓結局。

- 🎯 **適合**:國小中高年級(9–12 歲)與闔家同樂
- 🧩 **內容**:12 個房間 × 4 層樓、10 道公平謎題、像短篇小說的完整劇情
- 💛 **調性**:溫馨有趣、完全不恐怖、保證 Happy ending
- 🎨 **美術**:全部由純前端 SVG/CSS 手繪繪製(溫馨繪本風),無外部圖檔、無音效
- 📱 **裝置**:手機優先(直式,iPhone 16 Pro 最佳化),桌機自動切換側欄版面

## 玩法
- 在標題畫面輸入小主角的名字(不填預設「小米」),按「開始遊戲」。
- 點擊場景中的物件探索;桌面/檯面點下去會有**俯視特寫**看清上面的東西。
- 右上角:🔎 偵探筆記(自動記錄線索)、💡 提示(每題 2–3 段漸進式提示)、↻ 重來。
- 解開關鍵路徑的謎題,一路爬到頂樓,迎接全家的驚喜!

## 本機執行
純靜態網站,無需安裝套件:

```bash
python3 serve.py 8000      # 或 python3 -m http.server 8000
# 瀏覽器開 http://localhost:8000
```
