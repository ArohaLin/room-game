# 美術與 UI(美工)

## 風格指南
- 色彩:以暖色為主的繪本調色:奶油黃打底、暖橘與柔粉做重點、淺木色構築家具、薄荷綠與天空藍只做點綴。絕不用大面積純黑(改用深可可棕 #5B4636 做線稿與深色),也不用高飽和刺眼色。每個房間設計兩套色階變量:進入時為『偏冷清版』(降低明度與飽和約 15%、暖燈關閉),解開該房關鍵謎題後切換為『被點亮版』(暖燈亮起、加上一層暖橘徑向光暈、飽和度回升),作為敘事即獎勵的視覺回饋。光源一律為柔和暖光,陰影只用『同色系更深一階+降透明度』的色塊表示,絕不畫寫實黑色陰影。
- 線條:統一圓潤手繪線:線稿色為深可可棕 #5B4636(非純黑),線寬一致偏粗(主物件描邊約 3-4px、細節 2px),所有轉角一律圓角(stroke-linejoin=round、stroke-linecap=round)。刻意營造『略帶不完美的手繪感』:用 SVG filter 的 feTurbulence+feDisplacementMap 給描邊加極輕微的抖動位移,讓直線微微歪斜、像鉛筆/蠟筆描的;封閉色塊不填到滿邊,留 1-2px 白邊或讓填色稍微溢出線外一點點,模仿小孩著色的可愛感。禁止尖角、破碎線、細密寫實紋理。
- 字體:使用系統可用的圓體/黑體中文字型堆疊(font-family: 'PingFang TC','Heiti TC','Microsoft JhengHei',sans-serif),不載入任何外部字型。字級偏大:敘事正文 18-20px、行高 1.8;謎題題目 20-22px 加粗;按鈕與房間名 16-18px。字色用深可可棕 #5B4636 而非純黑,降低對比銳利感;重要關鍵字用暖橘 #F0944D 標色但同時加底線或加粗,確保不只靠顏色辨識。標題類可用稍微旋轉 ±1deg 與字距加寬,呼應手繪歪斜感。
- 氛圍:像一本翻開的兒童繪本短篇小說:溫馨、安全、好奇、帶點尋寶的雀躍。全程明亮通透、有陽光與暖燈的居家感,完全無恐怖、無陰森。隨著玩家逐層往上,整棟房子從『安靜等待』漸漸『一盞盞被點亮』,情緒從『大家去哪了?』的溫柔懸念,推進到頂樓團圓的最溫暖最明亮高潮。

## UI
- 導覽:房間導覽採『點擊式熱區+方向箭頭』雙軌:在房間畫面內,可互動的門/通道做成明顯的圓角發光熱區(滑鼠靠近時加暖色描邊與輕微放大);畫面左右下角放圓潤的『上一間/下一間』或『回到走廊』暖橘圓形箭頭按鈕(直徑夠大,約 56px,間距充足),按鈕同時有箭頭圖示+文字,不只靠顏色。每個房間左上角顯示當前房間名稱牌(奶油黃圓角小牌+手繪外框)。
- 樓層切換:螢幕右側固定一個『手繪房子剖面樓層圖』作為樓層切換器:畫成一棟 4 層的可愛房子剖面(4F 頂樓加蓋→1F),每層是一個圓角格子標著樓層與房間。目前所在樓層/房間高亮(暖橘填色+小箭頭指示);已點亮(解過謎)的房間顯示為『暖燈亮起』的金黃色,未到訪的顯示為柔和灰調但仍可辨識——用『燈泡亮/暗圖示+顏色』雙重編碼,不只靠顏色。點任一房間格子可直接跳轉(已解鎖的房間),鎖住的房間顯示小圓鎖圖示並提示需先完成前面的線索。
- 物品欄:底部或右下角的圓角物品欄:一排奶油黃圓角格子(每格約 64px、圓角 12px、手繪描邊),撿到的道具以可愛圓潤 SVG 圖示呈現。格子滑入時輕微放大+暖色光暈提示『這裡有東西』。點選道具放大檢視(置中彈出圓角卡片,顯示道具大圖+一段觀察描述文字),可拖曳或點兩下對房間熱點『使用道具』。空格顯示淡淡的虛線圓角佔位,讓孩子知道還能收集更多。道具同時有圖示+名稱文字標籤。
- 對話框:畫面底部一條暖色(奶油黃→淺橘漸層)圓角大文字框,佔寬約 80%、置中、上緣有手繪波浪邊或圓角;左側可放一個小小的『說話的人』圓臉頭像(可選),文字區字級 18-20px、行高 1.8、深可可棕字色、留白充足。文字逐字浮現(CSS/JS 打字機效果,可一鍵跳過全顯)。多段敘事用右下角圓潤『▶ 繼續』按鈕推進;謎題的成功/失敗回饋也用此框,成功時框體加一圈暖橘光暈與小星星 SVG,失敗時溫柔語氣不責備、不變紅。
- 提示按鈕:右下角固定一顆明顯但不干擾的圓形『燈泡小幫手』按鈕(暖橘底、白色圓潤燈泡圖示,直徑約 56px,平時輕微呼吸發光動畫吸引但不晃眼)。點下彈出圓角提示卡,提供當前謎題的 2-3 段漸進式提示(第一段點方向、第二段縮小範圍、第三段近乎給答案),一次只展開一段,要看下一段需再點『還是想不到?再給一點提示 💡』。語氣設計成溫柔家人在旁鼓勵(例『別急,再看看月曆上被圈起來的地方喔』)。提示卡同時用燈泡圖示+文字,不只靠顏色;在純氛圍房則顯示『這個房間沒有謎題,放輕鬆逛逛吧～』。

## 繪製可行性
全部畫面以純前端 SVG+CSS 程式繪製、無任何外部圖片/字型/音檔,離線可玩。可行性如下:

【手繪歪斜感】1) 用 SVG <filter> 的 feTurbulence(type='fractalNoise',baseFrequency≈0.02,numOctaves=2)+feDisplacementMap(scale≈2-3)套在線條圖層上,讓直線/圓角產生極輕微的有機抖動,模擬鉛筆/蠟筆描邊;同一 filter 可全站重用,效能良好。2) 線稿用 stroke-linejoin='round'、stroke-linecap='round'、固定偏粗 stroke-width,線色用深可可棕 #5B4636 而非純黑。3) 著色用『稍微溢出線外/不填滿』:把填色形狀比描邊形狀略大或略小 1-2px,模仿小孩著色。

【柔和暖色與材質】用 SVG <linearGradient>/<radialGradient> 做奶油黃→暖橘的柔和漸層當牆面/光暈;陰影一律用同色系更深一階的半透明色塊(fill-opacity≈0.15-0.25),絕不用黑色寫實陰影。木紋/格紋用 <pattern> 平鋪簡單圓潤線條即可,避免寫實貼圖。

【房間『被點亮』的視覺獎勵】每個房間 SVG 用 CSS class 切換兩種狀態:.room--dim(對整個 <g> 加 filter:saturate(0.85) brightness(0.92) 或疊一層冷色半透明遮罩)與 .room--lit(移除遮罩、淡入一個暖橘 radialGradient 光暈、暖燈圖層 opacity 0→1)。用 CSS transition(0.8s ease)做平滑漸亮,純前端即可,無需任何資源。

【動態與生命感】輕量 CSS animation/@keyframes:落地燈/吊燈的呼吸光暈、陽台衣物隨風微擺(transform-origin 在繩子處小角度 rotate 往返)、提示燈泡的呼吸發光、熱點 hover 放大。全用 transform/opacity,效能佳、不卡。

【字型】只用系統字型堆疊('PingFang TC','Heiti TC','Microsoft JhengHei',sans-serif),零外部依賴;標題用 CSS transform:rotate(±1deg)+letter-spacing 製造手寫歪斜。

【互動熱點】房間 SVG 內可點擊物件用透明或半透明的 <rect>/<path> 熱區覆蓋,綁定 click;hover 時加 filter:drop-shadow(暖色)或描邊高亮,確保孩子一眼看出可點;熱區尺寸與間距加大符合 9-12 歲。

【UI 元件】房子剖面樓層圖、物品欄格子、敘事框、燈泡按鈕全部用 SVG+CSS 圓角矩形與圖示繪製;打字機效果用 JS 逐字插入 textContent + CSS 顯示。重要狀態(已點亮/鎖住/有道具)一律『圖示形狀+顏色』雙重編碼,符合無障礙。

【效能/離線】整站可打包為單一 HTML(內嵌 SVG defs、CSS、JS),無網路請求即可運行;SVG defs(filter/gradient/pattern)集中定義一次全站引用,DOM 數量可控。結論:本美術規格 100% 可用純前端 SVG/CSS 離線實現手繪繪本感。

## 各房間美術
### 前院(停車空間)
- 場景:清晨/午後的住家門口:一棟暖色系兩層可見立面的小房子大門半開、門前一條圓石步道、左側有停車空間(車位空著,只停了一台小腳踏車)、右側立著一個圓筒造型的紅色信箱。天空是柔和的天空藍漸層,飄幾朵圓圓的雲。
- 主要元素:半開的木質大門(門縫透出室內暖光)、圓筒紅信箱(旗子立起,暗示有信)、空車位+一台小孩腳踏車、圓石步道與圓潤花圃、一棵圓樹冠的樹、門把上掛著的一張手寫字條
- 互動熱點:門把上的手寫字條(開場線索:點開讀『我們在樓上,上來找我們呀』之類善意懸念)、紅信箱(撿取第一封信/鑰匙,入門教學:教會點擊與撿道具)、半開的大門(點擊進入客廳)、腳踏車(觀察描述:暗示有孩子在家,氛圍)
- 氛圍:溫柔的好奇與期待。光線明亮、無一絲陰森;懸念是善意的『大家去哪了?』。被點亮版:門縫暖光更明顯、天空更金黃。

### 客廳
- 場景:溫馨起居室:一張圓角大沙發鋪著格紋抱枕、牆上掛一排圓角相框、旁邊牆面掛著一本大大的桌曆/月曆、矮茶几上有遙控器與一杯還溫的茶、角落有一盞圓罩落地暖燈。

- 互動熱點:牆上月曆(放大檢視被圈起的日期,記下數字/暗示驚喜日)、家庭相框(觀察家庭成員,情感鋪陳)、沙發抱枕底下(翻找可撿到小道具)、落地暖燈開關(解謎後點亮客廳的回饋互動)
- 氛圍:家的氣味與溫度,安心。能感覺剛剛還有人在這裡。是建立家庭成員與第一條線索的核心敘事房。
