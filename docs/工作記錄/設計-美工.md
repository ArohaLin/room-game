# 工作記錄 — 美工(設計)

## 提出的方案
- 提出統一的『溫馨手繪繪本風』視覺風格指南:深可可棕圓潤線稿(非純黑)、柔和暖色漸層、刻意的手繪歪斜與溢色感,並用 SVG feTurbulence+feDisplacementMap 全站重用以實現抖動手繪感。
- 提出 10 色暖色調色盤(奶油黃打底、暖橘/柔粉做重點、淺木色構家具、薄荷綠/天空藍點綴),並為每個房間設計『偏冷清版↔被點亮版』兩套色階,作為『敘事即獎勵』的視覺回饋機制。
- 為 canonical 12 個房間各產出一份美術規格:場景、主要視覺元素、可點擊互動熱點、氛圍,並明確標示一樓廁所、主臥衛浴為純敘事/氛圍房以製造節奏呼吸。
- 提出四大 UI 元件設計:點擊熱區+方向箭頭的房間導覽、手繪房子剖面圖樓層切換器(燈泡亮暗雙重編碼)、圓角可愛物品欄(點選放大檢視)、暖色圓角打字機敘事框、呼吸發光的燈泡漸進提示按鈕。
- 提出純前端離線可行性方案:全 SVG/CSS 繪製、系統字型、CSS 兩態切換實現『房間被點亮』、輕量 CSS 動畫做生命感、單一 HTML 內嵌可離線運行。

## 做出的決策
- 決定線稿色採深可可棕 #5B4636 取代純黑,避免大面積純黑與銳利對比,維持安全可愛感(對齊總監『避免大面積純黑』指示)。
- 決定以『房間 dim→lit 兩態 CSS class 切換』作為解謎獎勵的統一視覺語言,讓整棟房子隨劇情逐層被點亮,於 4F 健身房達到最亮最暖高潮。
- 決定所有重要狀態(已點亮/鎖住/有道具/成功失敗回饋)一律採『圖示形狀+文字+顏色』雙重以上編碼,不只靠顏色,符合 9-12 歲無障礙適配。
- 決定小孩房A(藍綠/運動星空/活潑)與小孩房B(柔粉/繪本絨毛/溫柔)在配色與主題上明確區分,以視覺呈現手足個性差異(對齊『兩間風格要可區分』驗收標準)。
- 決定青春愛情副線僅以書房一張卡片/信的純真細節呈現,視覺上點到為止不喧賓奪主,服務親情主題。
- 決定嚴格沿用 canonical 12 房間命名,所有美術規格與 UI 文字不新增、不改名房間。
