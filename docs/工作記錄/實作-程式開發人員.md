# 工作記錄 — 程式開發人員(實作)

## 提出的方案
- 採模組化純前端架構:`index.html` + `css/styles.css` + `js/data.js`(內容/唯一真實來源)+ `js/art.js`(SVG 手繪場景)+ `js/game.js`(引擎),零相依、離線可玩。
- 美術採「SVG 背景 + 百分比定位的 HTML 熱點按鈕」雙層:美術與互動解耦,點擊判定穩定。
- 互動一律用「點選」而非拖曳(對 9-12 歲與觸控更友善):配對=點左再點右、排序=▲▼、拼圖=點兩格交換、密碼=數字鍵盤、顏色順序=依序點卡。
- 未解謎房間以 CSS 柔光罩呈現「偏冷清」,解謎後移除作為「點亮」回饋(對應美工的兩套色階方案,以較穩健方式實現)。

## 做出的決策

- 偵探筆記、漸進提示、物品欄、樓層導覽、localStorage 自動存檔、標題「繼續/重來」全部實作。
- 嚴格綁定凍結版答案:P7=337、P8 順序紅黃綠藍→2615、P9=2615、P10=蛋糕→氣球→燈串。
- 顏色卡一律「顏色+形狀+數字」三重編碼(♥2/◆5/★6/♣1),落實無障礙裁決 D8。
