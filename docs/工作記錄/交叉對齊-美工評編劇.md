# 工作記錄 — 美工(交叉對齊(評編劇))

## 提出的方案
- 提出產出一張『房間↔角色↔謎題↔是否純敘事房』單一真實來源對照表,作為編劇/美術/工程三方對齊基準,消除目前劇情大綱、謎題表、美術規格三份文件互相矛盾的房間歸屬。
- 提出書房以『兩次進房狀態切換』分區呈現 P7 與 P9,降低單一畫面熱點密度;陽台 P8 加畫太陽方向標示與每件衣服的形狀/編號雙重編碼,並補足黃、綠兩色的前置實證線索。
- 提出純敘事房熱點精簡到2-3個精華,並在燈泡提示與樓層剖面圖同步標記『此房無謎題』,避免玩家在無謎題房空轉。
- 提出用樓層剖面圖『同層房間逐一點亮金黃』將雙支線橫向探索可視化為『點滿本層再上樓』,調和雙支線並行與逐層向上點亮的節奏衝突。

## 做出的決策
- 決定本次僅提一輪意見(依任務限制),聚焦房間使用合理性、熱點密度、敘事節奏與畫面切換、難以視覺化的設定四面向。
- 決定維持既有暖色手繪繪本風與純前端 SVG/CSS 離線實現方案不變,問題集中在房間-內容對齊而非視覺風格本身。
- 決定主張將『主臥衛浴』因承載關鍵題 P6 而正式改列為謎題房,純敘事房固定為一樓廁所(及視玩具謎題去留的小孩房B)。

## 完成的任務
- 檢視專案目錄確認為空白 greenfield,無既有畫面可截圖,故以文件交叉比對方式檢視。
- 交叉比對編劇劇情大綱、10 題謎題規格、關鍵路徑 DAG 與自身12房美術規格,找出房間歸屬、熱點分布、節奏與視覺化四類問題共7項。
- 完成從美工與玩家體驗角度的一輪檢視意見,含每項問題的具體視覺/體驗修正建議。

## 與其他角色的溝通
- 對編劇:提出7項對齊需求,核心為小孩房A/B與主臥房的角色-擺設-謎題歸屬需統一(玩具排序建議移至妹妹房、哥哥卡片實物放哥哥房)、餐廳需明確定位(純敘事或補輕線索)、主臥衛浴純敘事與關鍵題 P6 的定位矛盾需定案、P7 拿掉會誤導的符號對照表、P8 補足黃綠兩色前置線索。
- 對工程:書房建議以兩次進房狀態切換分區 P7/P9,樓層剖面圖需支援同層房間個別點亮狀態以引導雙支線探索;純敘事房需可在燈泡提示回傳『無謎題』標記。
