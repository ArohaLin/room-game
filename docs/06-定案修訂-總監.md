## 凍結後關鍵路徑(實作=測試 oracle)

1. **P1 前院**:信箱→拿「家門鑰匙」→開門進客廳。
2. **P2 客廳**:看月曆紅圈=6 號(蛋糕圖,情感線索)→ 解鎖 2F。〔1F 廚房、餐廳、一樓廁所進門後即可逛〕
3. **P3 廚房**:食譜配對(蛋3檸2粉1糖1)→ 得數字 **3**。
4. **綠葉卡=1**:一樓廁所 塗鴉(小米最愛的綠色大樹)→ 得綠葉卡。
5. 〔解 P2 後上 2F〕**P4 小孩房A**:玩具由矮到高排序 → 得 **37**。
6. **黃星卡=6**:小孩房B 蠟筆筒(用到見底的黃色蠟筆)→ 得黃星卡。
7. **P5 主臥房**:拼好奶奶與小米合照 → 得紅心卡(紅=2)→ 解鎖主臥衛浴。
8. **P6 主臥衛浴**:對鏡哈氣起霧 → 得藍方卡(藍=5)→ 解鎖 3F。
9. **P7 書房**:輸入 337(=3 與 37)開驚喜計畫文件 → 揭示「抽屜密碼=陽台顏色順序數字」規則 + 哥哥卡片青春副線。
10. **P8 前陽台**:依分工表序 紅→黃→綠→藍(右起),用四色卡數字 → 得抽屜密碼 **2615**。
11. **P9 書房抽屜**:輸入 2615 → 取得「頂樓鑰匙」→ 解鎖 4F。
12. **P10 家庭健身房**:用鑰匙開門 → 依序按 蛋糕→氣球→燈串 → 全室點亮,全家現身「歡迎回家」→ 結局。
